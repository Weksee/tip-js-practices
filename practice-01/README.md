## Задание 1

Файл `hello.js` запущен двумя способами:

1. **Node.js** — командой `node practice-01/js/hello.js` из корня репозитория.
2. **Браузер** — через `practice-01/index.html`, вывод смотрел во вкладке Console в DevTools.

Вывод совпадает, кроме последней строки:

| Среда | `typeof document` |
|---|---|
| Node.js | `undefined` |
| Браузер | `object` |

**Объяснение.** `document` — это объект DOM, который предоставляет браузер для работы с HTML-страницей. Node.js не создаёт HTML-страницу и не имеет DOM, поэтому `document` в нём не определён (`undefined`). Один и тот же файл работает в обеих средах, но браузерные объекты доступны только в браузере.
