## 4. Контракт и примеры ответов
Сервер поддерживает:
- `GET /api/health` → `200 { data: { status: "ok" } }`
- `GET /api/categories` → `200 { data: [...], meta: { total } }`
- `GET /api/tasks` → `200 { data: [...], meta: { total, filters } }`
- `GET /api/tasks/:id` → `200 { data: task }`

**Пример успешного ответа (фильтр по высокому приоритету):**

**Пример ошибки (некорректный id):**
```json

  "error": {
```

## 5. Проверка параметров
- **ID:** функция `parsePositiveId` проверяет регулярным выражением `/^[1-9]\d*$/` и `Number.isSafeInteger`. Строки вроде `4abc`, `01`, `1.5` отклоняются.
- **Повторения:** с помощью `searchParams.getAll()` проверяется, что каждый параметр встречается не более одного раза.
- **Значение false:** сравнивается строго со строкой `"false"`, чтобы избежать ошибки `Boolean('false') === true`.

## 8. Исправленный дефект
При реализации возникла ошибка: фильтр `completed=false` возвращал выполненные задачи, потому что использовалась проверка `if (filters.completed)`, а `false` является ложным значением. Исправлено на явное сравнение `filters.completed !== null`.

## 9. Ответы на контрольные вопросы
1. **Чем Node.js отличается от браузера?** В Node.js нет DOM, `window` и `localStorage`. Есть доступ к файловой системе и сети.
2. **Что определяет маршрут?** Путь и HTTP-метод (query-параметры не участвуют в выборе маршрута).
3. **Чем `req.params` отличается от query?** `params` — часть пути (`/tasks/:id`), query — параметры после `?`.
4. **Почему `'false'` требует явного преобразования?** `Boolean('false')` равно `true`, поэтому нужно сравнивать строку.
5. **Зачем проверять весь id?** Чтобы `4abc` не превратилось в `4` (parseInt не подходит).
6. **Почему пустая выборка — 200, а отсутствующая задача — 404?** Пустая выборка — успешный запрос, отсутствие ресурса — ошибка.
7. **В чём различие `TASK_NOT_FOUND` и `ROUTE_NOT_FOUND`?** Первое — нет задачи по id, второе — нет такого маршрута.
8. **Чем 405 отличается от 404?** 405 — метод не поддерживается для существующего пути, 404 — путь не найден.
9. **Что означает `meta.total` при фильтрах?** Количество записей в выборке, а не всего хранилища.
10. **Как порядок middleware влияет на результат?** Если 404 стоит раньше роутера, он перехватит все запросы.
11. **Почему обработчик ошибок имеет 4 параметра?** Express определяет его по сигнатуре.
12. **Зачем фабрика приложения отделена от запуска?** Для тестов можно создать приложение без открытия порта.
13. **Какие данные отправлять при внутренней ошибке?** Только общий текст, без стека и служебных данных.
14. **Почему CORS не авторизация?** CORS — правило браузера, а не проверка прав пользователя.
15. **Что потребуется для ПР10?** Добавить POST/PATCH/DELETE и подключить клиент ПР8.
